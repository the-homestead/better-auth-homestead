# Support

Use GitHub issues for reproducible bugs and focused feature requests. Include package and runtime
versions, a minimal reproduction, expected behavior, and actual behavior.

This project does not provide private integration consulting, credential debugging, or guaranteed
response times. Questions about Better Auth itself belong in Better Auth's official support channels.
Provider outages and account restrictions belong with Steam or Cfx.re support.

Report security issues privately according to [SECURITY.md](SECURITY.md).
