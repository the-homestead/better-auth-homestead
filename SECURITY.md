# Security Policy

## Supported versions

Security fixes are provided for the latest released version of each public package. Packages marked
as private scaffolds have not been released and must not be used in production.

## Reporting a vulnerability

Do not report vulnerabilities in public issues, discussions, or pull requests. Use the repository's
[private vulnerability reporting form](https://github.com/the-homestead/better-auth-homestead/security/advisories/new)
or email [support@homestead.systems](mailto:support@homestead.systems).

Include the affected package and version, impact, reproduction steps, and any suggested mitigation.
Remove live credentials and personal account data. Homestead Systems maintainers will acknowledge the report,
assess its impact, and coordinate disclosure and remediation through the private advisory.
