# @itzdabbzz/better-auth-cfx

A Better Auth Cfx plugin from Homestead.

> [!IMPORTANT]
> This workspace is a private scaffold. Its provider implementation is not complete and it cannot
> be published until `private: true` is removed from `package.json`.

## Installation

Installation and configuration instructions will be added with the provider implementation.

## Development

From the repository root:

```bash
bun install
bun --filter "@itzdabbzz/better-auth-cfx" test
bun --filter "@itzdabbzz/better-auth-cfx" build
```
